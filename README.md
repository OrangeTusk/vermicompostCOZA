# Vermicompost Farm

Website rebuild for [vermicompostfarm.co.za](https://www.vermicompostfarm.co.za), built with Astro for Cloudflare Pages.

The deployable project is in [`site`](site). It includes the public website, enquiry basket, Cloudflare Pages email function and the Sanity Studio schemas.

## Cloudflare Pages build settings

- Root directory: `site`
- Build command: `pnpm build`
- Build output directory: `dist`
- Node version: `22`

See [`site/README.md`](site/README.md) for development, environment and CMS setup.
